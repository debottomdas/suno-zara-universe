# Suno Zara Universe — Music Frontend V3

Refinement pass after local browser review.

## Changes
- Warmer cinematic hero artwork and stronger Music identity.
- Existing project cover art is loaded into the song cards when available.
- Active song cover art is shown in the project header when available.
- Release workflow stays deliberately quiet until a finished Suno audio file exists.
- Existing Final Audio is detected through the current media API.
- Once Final Audio exists, video generation, review, and publishing panels become visible.
- Connected platform badges now reflect the existing publishing-connections API instead of being hard-coded.
- Create panel uses a softer champagne tone; Release remains deep petrol/teal.
- Universe Assistant column is slightly wider and the main calls-to-action have stronger visual priority.

## Backend
No backend route was changed in this patch. It only uses APIs already present in the project.
